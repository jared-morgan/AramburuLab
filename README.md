# Aramburu Lab Website

This is the website of our academic research group at Umeå University.

This website is powered by Jekyll and some Bootstrap, Bootwatch. 

Website forked from Allan Lab's in Leiden University. Go to [aboutwebsite.md](https://github.com/mpa139/allanlab/blob/gh-pages/_pages/aboutwebsite.md)  to learn how to copy and modify [Allan Lab's page](https://github.com/mpa139/allanlab) the way we did it. 

## How to update the website

### Add a new team member

1. Copy the example team member file from [_examples/example_team_member.yml](https://github.com/AramburuLab/AramburuLab/blob/gh-pages/_examples/example_team_member.yml) to [_data/team_members.yml](https://github.com/AramburuLab/AramburuLab/blob/gh-pages/_data/team_members.yml).
2. Edit the new file to add your team member information.
3. Add the team member image to the `/images/team/` directory.
4. Commit and push the changes to the repository.   

### Add a new publication

1. Copy the example publication file from [_examples/example_publication.md](https://github.com/AramburuLab/AramburuLab/blob/gh-pages/_examples/example_publication.md) to [_publications/](https://github.com/AramburuLab/AramburuLab/blob/gh-pages/_publications/).
2. Edit the new file to add your publication information.
3. Add the publication image to the `/images/publications/` directory.
4. Add the publication PDF to the `/downloads/` directory.
5. Commit and push the changes to the repository.
